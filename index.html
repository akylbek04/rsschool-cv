Code Example

Codewars Kata: Sum of Digits / Digital Root (6 kyu) — Given a non-negative integer, return its digital root: the recursive sum of all digits until a single digit remains. 

function digitalRoot(n) {
  if (n < 10) return n;
  return digitalRoot(
    n.toString()
      .split('')
      .reduce((sum, digit) => sum + Number(digit), 0)
  );
}

// Examples:
// digitalRoot(16)   => 1 + 6 => 7
// digitalRoot(942)  => 9 + 4 + 2 => 15 => 1 + 5 => 6
// digitalRoot(132189) => 24 => 6
// digitalRoot(493193) => 29 => 11 => 2
